# Лабораторная работа 2. Вычисления и проверка результата

## 1. Перевод времени

Файл: `time_parts.py`

Пример проверки:

Ввод:
`3671`

Результат:
`1 ч 1 мин 11 с`

Дополнительные проверки:
- `0` → `0 ч 0 мин 0 с`
- `59` → `0 ч 0 мин 59 с`
- `60` → `0 ч 1 мин 0 с`
- `3600` → `1 ч 0 мин 0 с`

## 2. Стоимость покупки

Файл: `purchase.py`

Пример проверки:

Ввод:
- цена = `45`
- количество = `3`
- передано = `200`

Результат:
- стоимость = `135`
- сдача = `65`

Дополнительные проверки:
- `45, 3, 135` → стоимость `135`, сдача `0`
- `45, 0, 100` → стоимость `0`, сдача `100`

## 3. Предсказание результата

До запуска Python:

- `2 + 3 * 4` → `14`
- `(2 + 3) * 4` → `20`
- `17 // 5` → `3`
- `17 % 5` → `2`
- `-7 // 2` → `-4`

Результаты Python:

- `2 + 3 * 4` → `14`
- `(2 + 3) * 4` → `20`
- `17 // 5` → `3`
- `17 % 5` → `2`
- `-7 // 2` → `-4`

Различий не появилось.

## 4. Индивидуальный вариант

Мой вариант: 1.

Общий объём — количество студентов.  
Вместимость одной единицы — количество мест в автобусе.

Файл: `variant.py`

Проверки:

- `0, 10` → полных `0`, остаток `0`, всего `0`
- `20, 10` → полных `2`, остаток `0`, всего `2`
- `21, 10` → полных `2`, остаток `1`, всего `3`

## Что нужно понимать

`/` — обычное деление, результат может быть дробным.

`//` — целочисленное деление с округлением вниз.

`%` — остаток от деления.

Форматирование числа, например `:.2f`, меняет только его отображение, но не хранимое значение `float`.
