## 1_1_profile.py
Программа запрашивает фамилию, имя, группу, город, возраст, любимый предмет и часы подготовки в неделю
### Проверка
Ввод:
```text
Возраст: 17
Часов подготовки в неделю: 10.5
```
Ожидается:
```text
Возраст через 4 года: 21
Подготовка за 4 недели: 42.00 ч.
Подготовка в день: 1.50 ч.
```
### Дополнительная проверка
Ввод:
```text
Возраст: 0
Часов подготовки в неделю: 0
```

Ожидается:
```text
Возраст через 4 года: 4
Подготовка за 4 недели: 0.00 ч.
Подготовка в день: 0.00 ч.
```

## 1_3_debug.py

### Фрагмент А
Исходный результат - '23'.
Причина - значения были строками.
Исправление:
```python
print(int(first) + int(second))
```
Результат - '5'.
### Фрагмент Б
`input()` возвращает строку, поэтому перед сложением нужен `int()`.
Результат при вводе 17 - '18'.
### Фрагмент В
Ошибка была в порядке выполнения операций.
Исправление:
```python
average = (first + second + third) / 3
```
Результат - '7.0'.

## 1_4_swap.py
Программа меняет местами названия двух аудиторий через третью переменную.
### Проверка
Ввод:
```text
А-101
Б-202
```
Ожидается:
```text
Первая аудитория: Б-202
Вторая аудитория: А-101
```
Дополнительно проверено, что при одинаковых названиях результат не меняется.

## 1_5_variant.py
Индивидуальный вариант - 1.
Магазин - канцелярия.
### Проверка из задания
Ввод:
```text
Тетради - 3 шт. по 12.50 руб.
Ручки - 2 шт. по 20.00 руб.
Доставка - 10.00 руб.
Внесено - 100.00 руб.
```
Ожидается:
```text
Тетради - 37.50 руб.
Ручки - 40.00 руб.
Товары - 77.50 руб.
Всего - 87.50 руб.
Количество - 5
Сдача - 12.50 руб.
```

Дополнительно проверено:
- нулевое количество одной позиции;
- нулевая доставка;
- оплата без сдачи;
- название заказа из нескольких слов.
