# Лабораторная работа 3. Условия и логические выражения

## Файлы
- `3_1_minimum.py`-поиск минимума из трёх чисел.
- `3_2_calculator.py`-простой калькулятор.
- `3_3_point.py`-проверка принадлежности точки прямоугольнику.
- `variant.py`-определение категории заряда аккумулятора.

## Проверки

### 1. minimum.py
| Ввод | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| 2, 10, 3 | 2 | 2 |
| 5, 5, 5 | 5 | 5 |
| -4, 0, -2 | -4 | -4 |
| 8, 10, 3 | 3 | 3 |

### 2. calculator.py
| Ввод | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| 7 / 2 | 3.50 | 3.50 |
| 5 / 0 | Деление на ноль запрещено | Деление на ноль запрещено |
| 5 ? 2 | Неизвестная операция | Неизвестная операция |
| 7 + 2 | 9.00 | 9.00 |
| 7 - 2 | 5.00 | 5.00 |
| 7 * 2 | 14.00 | 14.00 |

### 3. point.py
| Ввод | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| 2, 2 | Внутри или на границе | Внутри или на границе |
| 5, 3 | Внутри или на границе | Внутри или на границе |
| 5.1, 3 | Снаружи | Снаружи |

### 4. variant.py
Вариант 1-**заряд аккумулятора**:
- 0-19: `Низкий`
- 20-79: `Средний`
- 80-100: `Высокий`

| Ввод | Ожидаемый ответ | Фактический ответ |
|---|---|---|
| -1 | Ошибка диапазона | Ошибка диапазона |
| 0 | Низкий | Низкий |
| 19 | Низкий | Низкий |
| 20 | Средний | Средний |
| 79 | Средний | Средний |
| 80 | Высокий | Высокий |
| 100 | Высокий | Высокий |
| 101 | Ошибка диапазона | Ошибка диапазона |
